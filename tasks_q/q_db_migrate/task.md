crm/ は、連絡先データベース（SQLite）をスキーマ v1 から v2 に移行するスクリプトです（`python3 -m crm.migrate DB`、仕様は docs/MIGRATION.md）。

利用者からの報告: 「本番のコピーで試したら、途中で `migration failed` になって止まり、その DB は v1 にも v2 にも戻せない中途半端な状態になった。別の DB では成功したように見えたが、名字と名前が逆になっている人がいて、もう一度実行するとエラーになる。」

docs/MIGRATION.md のとおりに動くように直してください。

- どんな v1 の DB でも、移行後の表・値・件数・出力が docs/MIGRATION.md のとおりになること（全角スペースの名前、タグの空白・大文字・重複・空の項目、存在しない連絡先へのメモなどを含む）。
- 失敗するときは DB を一切変えずに v1 のまま残し、仕様どおりのメッセージと終了コードを返すこと。v2 の DB で実行しても何も変えないこと。
- 移行後に連絡先を削除すると、そのメモとタグの関連づけも消えること（外部キー）。
- コマンドの使い方と出力の形式は変えないこと。
- data/ と tests/ の既存ファイルは変更しないこと（テストの追加は自由）。`python3 -m unittest discover -s tests` が通ること。

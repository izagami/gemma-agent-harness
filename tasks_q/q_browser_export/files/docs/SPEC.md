# 受注一覧の CSV 書き出し(automation/export.py)

受注管理システム(app/、社内の Web 画面)から全受注を CSV に書き出すスクリプト。
システムには画面しかない前提で、**ブラウザ操作(Playwright, Python, Chromium ヘッドレス)で取得する**。

## 使い方
`python3 automation/export.py` → `out/orders.csv` を作る(out/ がなければ作る)。終了時に `exported N orders` と表示して終了コード 0。

- 接続先: 環境変数 `APP_URL`(既定 `http://127.0.0.1:8765`)
- ログイン: 環境変数 `EXPORT_USER` / `EXPORT_PASS`(ログイン画面 `/login`)
- テスト用に画面を起動するには `python3 app/server.py`(ユーザー demo / パスワード demo123)。
  本番は応答が遅く、速さも毎回違う(`--delay 200,1500` などで再現できる)。

## 画面
- `/orders`: 受注一覧。10件ずつ、新しい順。「次へ」「前へ」でページ移動(読み込み中は「読み込み中…」)。
- 各行の「詳細」で注文詳細(担当者・備考)が出る。一覧には出ない。「閉じる」で閉じる。
- 「CSV出力」は旧機能で、保留中の注文が含まれず、担当者・備考もないので使えない。

## out/orders.csv の形式
- 1行目は見出し `order_id,customer,amount,status,owner,note`
- 2行目以降は全受注(状態に関係なくすべて)を **注文番号の昇順** に1件1行、各注文ちょうど1回。
- `amount` は整数(画面の `¥12,345` → `12345`、`¥-3,000` → `-3000`)。他の列は画面の文字のまま。
- 文字コード UTF-8(BOM なし)、改行は LF(`\n`)。
- `,` または `"` を含む値は `"` で囲み、中の `"` は `""` にする。それ以外は囲まない。

例:
```
order_id,customer,amount,status,owner,note
A-1001,北村工業,12000,受付,佐藤,
A-1002,"山田商事, 大阪支店",-3000,キャンセル,鈴木,"返品(""至急"")"
```

# 注文フォーム仕様

`/work/index.html` 1ファイル（CSS・JS は中に書くか、/work の別ファイル）。外部の URL は読み込まない。

## 入力欄（id は厳密にこのとおり）

| id | 要素 | ラベル | 規則（前後の空白は除いて判定） | エラー文（`<id>-error` 要素に表示） |
|---|---|---|---|---|
| name | `<input type="text">` | お名前 | 必須、20文字以内 | 空: `お名前を入力してください` / 長すぎ: `お名前は20文字以内で入力してください` |
| email | `<input type="text">` | メールアドレス | 必須、`/^[^\s@]+@[^\s@]+\.[^\s@]+$/` に一致 | 空: `メールアドレスを入力してください` / 不一致: `メールアドレスの形式が正しくありません` |
| product | `<select>` | 商品 | 必須。option の value は `""`（選択してください）, `A`, `B`, `C` | 空: `商品を選択してください` |
| qty | `<input type="text" inputmode="numeric">` | 数量 | 必須、1〜99 の整数。全角数字（例 `１２`）も受け付ける | 空: `数量を入力してください` / それ以外: `数量は1〜99の整数で入力してください` |
| coupon | `<input type="text">` | クーポン | 任意。空か `SAVE10`（大文字小文字を区別しない） | 無効: `クーポンコードが無効です` |

- ラベルは `<label for="...">` で各入力欄と結びつける。
- エラー要素 `name-error` などは常に存在し、エラーがないときは空文字。
- ある欄のエラーは、その欄から最初にフォーカスが外れた（blur）後に表示する。それより前は空。一度表示を始めた欄は、以後入力のたびに更新する。

## 商品と金額

| value | 商品 | 単価 |
|---|---|---|
| A | ノート | 480円 |
| B | ペン | 120円 |
| C | ファイル | 330円 |

- 小計 = 単価 × 数量（商品か数量が無効なら 0）
- 値引き = クーポンが有効なら 小計の10%（1円未満切り捨て）、それ以外 0
- 消費税 = (小計 − 値引き) の10%（1円未満切り捨て）
- 合計 = 小計 − 値引き + 消費税
- `#subtotal`, `#discount`, `#tax`, `#total` に `1,234円` の形（3桁区切り、末尾に「円」）で表示。入力のたびに（blur を待たずに）更新する。

## 送信

- ボタン `#submit`（`<button type="submit">`）は、全項目が有効なときだけ押せる（それ以外は disabled）。
- 押すとページは移動せず、`#result` の textContent に次の JSON を `JSON.stringify` で出す（キーの順もこのとおり）:
  `{"name": 名前(前後の空白を除く), "email": ..., "product": "A"|"B"|"C", "qty": 数値, "coupon": "SAVE10" か "", "total": 数値}`

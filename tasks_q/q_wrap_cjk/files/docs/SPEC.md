# jwrap の折り返し規則

## 幅

- 文字の表示幅: Unicode の East Asian Width が W（Wide）または F（Fullwidth）の文字は 2、
  結合文字（`unicodedata.combining(ch) != 0`。例: 結合用濁点 U+3099、アクセント U+0301）は 0、それ以外は 1。
- 「1 文字」とは、基底文字と、その直後に続く結合文字をまとめたもの（例: `か` + U+3099）。
  1 文字の途中では決して改行しない。その幅は含まれる文字の幅の合計。

## 折り返し（段落ごと）

入力は `\n` で段落に分け、段落ごとに折り返す（空の段落は空行 1 行になる）。
各段落は前から 1 文字ずつ現在の行に足していき、行の幅が WIDTH を超えるときに改行する:

1. 足すと WIDTH を超える文字が **行頭禁則文字** なら、改行せずに現在の行の末尾に付ける
   （ぶら下げ。幅を超えてよい）。行頭禁則文字が続く場合はすべてぶら下げる。
2. それ以外なら改行し、その文字から新しい行を始める。ただし、改行前の行が **行末禁則文字** で
   終わっていたら、末尾に連続する行末禁則文字を新しい行の先頭へ移す（移すと前の行が空になる場合は移さない）。
3. 1 文字だけで WIDTH を超える場合は、その文字だけの行になる。

行頭禁則文字: `。、，．・：；？！ー」』）］｝〕〉》】ぁぃぅぇぉっゃゅょゎァィゥェォッャュョヮヵヶ`
と半角の `) ] } , . ? !`

行末禁則文字: `「『（［｛〔〈《【` と半角の `( [ {`

## コマンド

`python3 -m jwrap [-w WIDTH] [FILE]` : WIDTH は既定 40、2 未満はエラー（`error: ...`、終了コード 2）。
FILE を省略するか `-` なら標準入力。最後の改行 1 つは無視し、各行を改行付きで出力する。

## 例（WIDTH = 10）

    あいうえおかきくけこ。さし   →   あいうえお / かきくけこ。 / さし
    ＡＢＣＤＥＦ                   →   ＡＢＣＤＥ / Ｆ
    あいうえ「かきくけ             →   あいうえ / 「かきくけ

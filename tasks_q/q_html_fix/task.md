index.html は売上データを表で見るための1ページの画面です（使い方と仕様は docs/README.md）。

利用者からの報告: 「金額の列で並べ替えると、9 が 100,000 より下に来るなど順番がおかしい。`tokyo` や全角の `ＴＯＫＹＯ` で絞り込むと何も出ない。日付が1日ずれている行がある（日本で見たとき）。『CSVを表示』を押しても何も起きない。スマホで開くと画面が横にはみ出して、左右にスクロールしてしまう。」

原因を調べて直してください。

- 並べ替え・絞り込み・日付の表示・合計・CSV の出力・スマホ幅での表示が、すべて docs/README.md のとおりになること。
- ブラウザ（Chromium）で開いたときに、コンソールにエラーが出ないこと。
- data.js と docs/ の既存ファイルは変更しないこと。外部の URL（CDN など）は使わないこと。

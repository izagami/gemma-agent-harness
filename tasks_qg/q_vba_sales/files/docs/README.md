# 月次売上集計マクロ

経理課で使っている Excel ブック「売上管理.xlsm」の標準モジュール `Module1`（`vba/Module1.bas` にエクスポート済み）。

## 使い方（現状）

1. シート「売上明細」に、その月の売上明細を貼り付ける（1行目は見出し）。
   - A: 日付（日付型、`yyyy/m/d` 表示） / B: 担当者 / C: 商品 / D: 数量（整数、返品はマイナス）
   - E: 単価 / F: 値引率（0.1 = 10% 引き、空欄のこともある）
2. マクロ「月次売上集計」を実行し、対象月を `yyyymm` で入力する。
3. ブックと同じフォルダに `report_yyyymm.txt`（タブ区切り）ができる。これを基幹システムに取り込んでいる。

`data/uriage_meisai.csv` は、2026年4月分の作業時点のシート「売上明細」を Excel の「CSV (コンマ区切り)」で保存したもの。
`out/expected_report_202604.txt` は、そのときマクロが出力した `report_202604.txt` そのもの。

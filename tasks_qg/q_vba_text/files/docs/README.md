# 顧客マスタ整形マクロ

情報システム課の Excel ブック「顧客マスタ.xlsm」の標準モジュール `Module1`（`vba/Module1.bas` にエクスポート済み）。
営業が入力したシート「顧客」を、基幹システムの取込ファイル `customers_load.txt`（タブ区切り）に整形する。

## シート「顧客」（1行目は見出し、セルはすべて文字列）

| 列 | 内容 |
|---|---|
| A | 顧客コード（`C` + 数字4桁のはず） |
| B | 氏名・会社名 |
| C | フリガナ（ひらがな・カタカナ混在） |
| D | 住所（都道府県から。建物名は最後のスペースの後ろ） |
| E | 電話（書き方はばらばら） |
| F | ポイント（手入力のメモ混じり） |

## ファイル

- `data/kokyaku.csv` … ある日のシート「顧客」を Excel の「CSV (コンマ区切り)」で保存したもの。
- `out/expected_customers_load.txt` … そのシートからマクロが出力した `customers_load.txt` そのもの。

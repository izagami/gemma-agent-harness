app/ は社内の受注管理システム(Web 画面)をまねたものです(`python3 app/server.py` で http://127.0.0.1:8765 に起動、ユーザー demo / パスワード demo123)。

経理から依頼: 「毎月、受注一覧を1件ずつ開いて担当者と備考を Excel に手で写している。画面の『CSV出力』では保留中の注文が抜けるうえ、担当者・備考も出ないので使えない。画面を自動で操作して、全受注を CSV にするスクリプトを作ってほしい。」

docs/SPEC.md の仕様どおりに、ブラウザ操作(Playwright)で全受注を out/orders.csv に書き出す automation/export.py を作ってください。

- 本番は件数がもっと多く、応答も遅くて速さが毎回違います。その環境でも、全受注がちょうど1回ずつ、SPEC の形式どおりに出ること。
- 接続先とログイン情報は SPEC のとおり環境変数から読むこと(テスト用の demo とは違うユーザーで動かします)。
- app/ の既存ファイルは変更しないこと。

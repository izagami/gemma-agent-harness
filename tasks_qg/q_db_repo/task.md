shop/repo.py は、ネットショップの Web アプリが使うデータアクセス関数です（SQLite、スキーマは data/schema.sql、仕様は docs/REPO.md）。

利用者からの報告: 「顧客一覧に同じ人が2回出たり、住所を登録していない人が出てこなかったりする。名前に `'` が入っている O'Brien さんを検索すると画面がエラーになる。商品検索で『50%』と入れると関係ない商品まで出てくる。注文履歴のページがとても遅い。」

原因を調べて直してください。

- docs/REPO.md のすべての関数が、どんなデータ・どんな入力文字列（`'`、`%`、`_`、`\` など）でも、docs/REPO.md のとおりの値と順番を返すこと。
- 商品一覧のページ送り（`products_page`）で、カーソルをたどると全商品がちょうど1回ずつ出てくること（同じ価格の商品が多くても）。
- `orders_with_items` は、注文が何件あっても SQL を2回以下しか実行しないこと。
- 関数の名前・引数・戻り値の形は変えないこと。
- data/ と tests/ の既存ファイルは変更しないこと（テストの追加は自由）。`python3 -m unittest discover -s tests` が通ること。

# 売上ダッシュボード（index.html）

ブラウザで index.html を開いて使う1ページの画面。データは data.js の `window.SALES`（書き出しデータ、編集しない）。

- 表 `#tbl`: 列は 名前 / 地域 / 金額 / 日付。最初は data.js の並び（id 順）。
- 見出しのクリックで並べ替え: 1回目は昇順、同じ見出しの2回目は降順、3回目はまた昇順。
  - 金額 (`th[data-key=amount]`) は数値として比べる。名前・地域は文字列として比べる。日付は時刻順。
  - 値が同じ行どうしは id の昇順。
- 金額は `12,345` の形（3桁区切り）で表示する。
- 日付は `date`（UTC の ISO 時刻）の **UTC での日付** を `YYYY-MM-DD` で表示する（閲覧者のタイムゾーンによらない）。
- 絞り込み `#filter`: 入力した文字列を名前か地域に含む行だけを表示する。大文字小文字を区別せず、全角英数字は半角と同じに扱う（例 `ＴＯＫＹＯ` は `Tokyo` に一致）。前後の空白は無視。空なら全件。
- `#sum`: 表示中の行の金額の合計を `合計: 12,345円` の形で表示する。
- ボタン `#export-btn`: 表示中の行を、表示中の順に CSV にして `#csv`（textarea）に入れる。1行目は `name,region,amount,date`、金額は区切りなしの数値、日付は表と同じ `YYYY-MM-DD`、行の区切りは `\n`、末尾に改行なし。
- スマートフォン（幅 375px）でもページ全体が横にはみ出さないこと（表だけは `.table-wrap` の中で横スクロールしてよい）。

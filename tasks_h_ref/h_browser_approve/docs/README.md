# 購買申請の一括承認

- app/: 購買申請の承認システム(社内 Web 画面)をまねたもの。`python3 app/server.py --store /tmp/store.json` で
  http://127.0.0.1:8772 に起動(ユーザー demo / パスワード demo123)。申請の状態と、承認操作の記録
  (処理済みで断られた操作も含む)が --store の JSON に保存される。
  本番は申請が多く、応答も遅くて速さが毎回違う(`--delay 300,2000` などで再現できる)。
- 画面 `/requests`: 検索欄に入力すると、少し待ってから一覧が検索結果に入れ替わる(部分一致、新しい順、最大 50 件)。
  行の「承認」→ 承認ダイアログでコメントを入れて「承認する」→ 確認 → 承認されると右下に数秒だけお知らせが出る。
- automation/approve.py: CSV の申請を画面から承認するスクリプト(使い方はファイル先頭の説明)。
- data/approve_list.csv: 承認する申請の例。
- 監査の決まり: 1つの申請に対して承認操作は1回だけ。リストにない申請、申請中でない申請に承認操作をしてはいけない。

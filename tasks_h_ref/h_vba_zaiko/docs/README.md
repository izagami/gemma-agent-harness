# 在庫評価表マクロ

物流課で使っている Excel ブック「在庫管理.xlsm」の標準モジュール `Module1`（`vba/Module1.bas` にエクスポート済み）。
月末の棚卸のあと、経理に渡す在庫評価表（移動平均法、ABC ランク付き）を作っている。

## シート

### 入出庫（1行目は見出し、入力した順に下へ追記）

| 列 | 内容 |
|---|---|
| A: 日付 | 日付型（`yyyy/m/d` 表示） |
| B: 品番 | 例 `A-1001`。倉庫担当が手入力するので小文字や前後の空白が混じることがある |
| C: 区分 | `入庫` / `出庫` / `調整`（棚卸差異。数量だけを直す。マイナスもある） |
| D: 数量 | 整数 |
| E: 単価 | 入庫のときだけ入れる（円、小数あり）。出庫・調整は空欄 |

途中に空行が入っていることがある。

### 品目（1行目は見出し）

| 列 | 内容 |
|---|---|
| A: 品番 | |
| B: 品名 | |
| C: 入数 | 1 ケースの個数。未設定の品目は空欄 |

## 使い方（現状）

1. 「入出庫」に当月分までの明細が入っている状態で、マクロ「在庫評価表」を実行する。
2. 基準日を `yyyy/mm/dd` で入力する（その日までの行だけを使う）。
3. ブックと同じフォルダに `zaiko_yyyymmdd.txt`（タブ区切り）ができる。区分の入力ミスなどがあるとメッセージが出て、ファイルは作られない。

`data/nyushukko.csv` と `data/hinmoku.csv` は、2026年4月末の棚卸のときのシート「入出庫」「品目」を Excel の「CSV (コンマ区切り)」で保存したもの。
`out/expected_zaiko_20260430.txt` は、そのとき基準日 `2026/04/30` でマクロが出力した `zaiko_20260430.txt` そのもの。

# 支払予定表マクロ

財務課の Excel ブック「支払管理.xlsm」の標準モジュール `Module1`（`vba/Module1.bas` にエクスポート済み）。
シート「請求」の請求ごとに締め日と支払予定日を計算し、`pay_schedule.txt`（タブ区切り）を作る。資金繰り表はこのファイルを読んでいる。

## シート「請求」（1行目は見出し、セルはすべて文字列）

| 列 | 内容 |
|---|---|
| A | 請求番号 |
| B | 請求日（`yyyy/m/d` の文字列。手入力なので誤りもある） |
| C | 取引先 |
| D | 支払条件（`末締め翌月末払い`、`20日締め翌月10日払い`、`納品後30日`、`2ヶ月後` など） |
| E | 金額 |

## ファイル

- `data/seikyu.csv` … ある日のシート「請求」を Excel の「CSV (コンマ区切り)」で保存したもの。
- `out/expected_pay_schedule.txt` … そのシートからマクロが出力した `pay_schedule.txt` そのもの。

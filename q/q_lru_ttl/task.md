ttlcache/ は、有効期限つきの LRU キャッシュです（仕様は docs/SPEC.md）。

利用者からの報告: 「期限が切れたはずのタイミングで、まだ古い値が返ってくることがある。よく読まれるキーは、いつまでたっても期限切れにならない。それと、キャッシュがいっぱいのときに、さっき使ったばかりのエントリが消えてしまうことがある。」

原因を調べて直してください。

- `TTLCache` のすべての操作（get / set / delete / len / in）と `stats()` の数値が、docs/SPEC.md の規則どおりになること。
- クラスの使い方（コンストラクタ、メソッドの名前と引数）は変えないこと。
- tests/ の既存ファイルは変更しないこと（テストの追加は自由）。`python3 -m unittest discover -s tests` が通ること。

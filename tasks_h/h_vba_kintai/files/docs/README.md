# アルバイト勤怠集計マクロ

総務課で使っている Excel ブック「勤怠管理.xlsm」の標準モジュール `Module1`（`vba/Module1.bas` にエクスポート済み）。
店舗から届いたタイムカードを転記したシートから、給与ソフトに取り込む `kyuyo_yyyymm.txt` を作っている。

## シート「勤怠」（1行目は見出し）

| 列 | 内容 |
|---|---|
| A: 日付 | 日付型（`yyyy/m/d` 表示）。メモ書きの行や空行が混じることがある |
| B: 社員番号 | 数値（給与ソフトでは 5 桁ゼロ埋め） |
| C: 氏名 | |
| D: 出勤 / E: 退勤 | 時刻型（`h:mm` 表示）。日付をまたぐ勤務は退勤のほうが小さい時刻になる。打刻漏れは空欄 |
| F: 休憩(分) | 分。店舗によっては「30分」のように書いてくる。休憩なしは空欄 |
| G: 時給 | 円。空欄は標準時給 |

行は転記した順で、日付順とは限らない。

## 使い方（現状）

1. 締め日（毎月15日）のあと、マクロ「勤怠集計」を実行し、支給月を `yyyymm` で入力する（前月16日～当月15日が集計される）。
2. ブックと同じフォルダに `kyuyo_yyyymm.txt`（タブ区切り）ができる。期間内の勤怠が 1 件もないとメッセージが出て、ファイルは作られない。

`data/kintai.csv` は、2026年4月支給分を集計したときのシート「勤怠」を Excel の「CSV (コンマ区切り)」で保存したもの。
`out/expected_kyuyo_202604.txt` は、そのとき支給月 `202604` でマクロが出力した `kyuyo_202604.txt` そのもの。

biblio/ は、図書館の貸出データベース（SQLite）をスキーマ v1 から v2 に移行するスクリプトです（`python3 -m biblio.migrate DB`、仕様は docs/MIGRATION.md）。

利用者からの報告: 「分館の DB で実行したら `migration failed` で止まり、その DB は loans_v1 という表ができた中途半端な状態になって、もう一度実行してもエラーになる。返却日が空欄の貸出があるだけの DB でも失敗した。成功した本館の DB では、朝早くに貸し出した本の日付が1日ずれていて、延滞金が 1 円少ない人や、同じ会員が2人に分かれている例がある。」

docs/MIGRATION.md のとおりに動くように直してください。

- どんな v1 の DB でも、移行後の表・値・件数・出力が docs/MIGRATION.md のとおりになること（日付をまたぐ時刻の変換、`/` 区切りの日時、空欄の返却日、浮動小数の延滞金、会員コードの空白や大文字小文字などを含む）。
- 失敗するときは DB ファイルを1バイトも変えずに残し、仕様どおりのメッセージと終了コードを返すこと。v2 の DB でもう一度実行しても何も変えないこと。
- 移行後は外部キーが仕様どおりに働くこと（本を削除するとその貸出も消える）。
- コマンドの使い方と出力の形式は変えないこと。
- data/ と tests/ の既存ファイルは変更しないこと（テストの追加は自由）。`python3 -m unittest discover -s tests` が通ること。

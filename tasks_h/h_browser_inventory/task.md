app/ は社内の在庫照会システム(Web 画面)をまねたものです(`python3 app/server.py` で http://127.0.0.1:8770 に起動、ユーザー demo / パスワード demo123)。

物流部から依頼: 「月末の棚卸しのたびに、在庫照会の画面を倉庫ごとに開いて『さらに表示』を押し続け、在庫数を Excel に手で写している。在庫 0 やマイナスの品目こそ確認したいのに写し漏れが多い。画面を自動で操作して、全倉庫の在庫を1つの CSV にするスクリプトを作ってほしい。」

docs/SPEC.md の仕様どおりに、ブラウザ操作(Playwright)で全倉庫の全品目を out/inventory.csv に書き出す automation/inventory.py を作ってください。

- 本番は倉庫も品目も多く、応答も遅くて速さが毎回違います。その環境でも、全品目がちょうど1回ずつ、SPEC の形式どおりに出ること。
- 接続先とログイン情報は SPEC のとおり環境変数から読むこと(テスト用の demo とは違うユーザーで動かします)。
- app/ の既存ファイルは変更しないこと。

# 全倉庫の在庫一覧 CSV(automation/inventory.py)

在庫照会システム(app/、社内の Web 画面)から、全倉庫の全品目の在庫数を CSV に書き出すスクリプト。
システムには画面しかない前提で、**ブラウザ操作(Playwright, Python, Chromium ヘッドレス)で取得する**。

## 使い方
`python3 automation/inventory.py` → `out/inventory.csv` を作る(out/ がなければ作る)。
終了時に `exported N items`(N はデータ行数)と表示して終了コード 0。

- 接続先: 環境変数 `APP_URL`(既定 `http://127.0.0.1:8770`)
- ログイン: 環境変数 `STOCK_USER` / `STOCK_PASS`(ログイン画面 `/login`)
- テスト用に画面を起動するには `python3 app/server.py`(ユーザー demo / パスワード demo123)。
  本番は倉庫も品目も多く、応答が遅くて速さも毎回違う(`--delay 300,2000` などで再現できる)。

## 画面(`/stock`)
- 倉庫ごとのタブ(`倉庫名 (倉庫コード)`)。倉庫の一覧は画面を開いてから読み込まれる。最初は先頭の倉庫が選ばれる。
- タブを押すと、その倉庫の在庫表を読み込み直す。読み込みが終わるまでは**前の表がそのまま表示されている**
  (読み込み中は表が薄くなる)。
- 表は棚番順に 20 件ずつ表示され、続きは「さらに表示」で追加される(全件出ると「さらに表示」は消える)。
  表の上に `表示中 X / 全 Y 件`。
- 「在庫ありのみ表示」は最初からオンで、在庫数 0 以下の品目は表示されない。オフにすると全品目が出る
  (切り替えると表を読み込み直す)。品目が1つもない倉庫は「該当する在庫はありません」と出る。
- 在庫数は3桁区切り(`1,234`)、マイナス(引当超過)は `▲1,234` と表示される。

## out/inventory.csv の形式
- 文字コード UTF-8(BOM なし)、改行 LF。
- 1行目は見出し `warehouse,sku,name,qty`
- 2行目以降は全倉庫の全品目(在庫数 0 以下も含む)を、**倉庫コードの昇順、同じ倉庫内は SKU の昇順** に1件1行、
  各品目ちょうど1回(同じ SKU が別の倉庫にあれば、それぞれ1行)。
- `warehouse` は倉庫コード(例 `TKY`)、`name` は画面の品名そのまま、`qty` は整数(区切りなし、マイナスは `-1234`)。
- 引用符は必要な欄だけに付ける(カンマ・ダブルクォートを含む欄。Python の csv モジュールの既定どおり)。

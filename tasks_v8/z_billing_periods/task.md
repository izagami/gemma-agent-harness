billing/ はサブスクリプションの請求書を作るパッケージです（`python3 -m billing invoice --on 日付 顧客ID`、`python3 -m billing run --on 日付`。使い方は billing/cli.py、請求書の形式と期間・日割りのルールは docs/FORMAT.md）。サポートに次の問い合わせが来ています。

- C003（1月31日に契約）: 「3月20日時点の請求書の期間が 2026-02-28..2026-03-27 になっている。FORMAT.md の例では 2026-02-28..2026-03-30 のはず。4月以降の請求期間もずれている」
- C005（同じく1月31日契約、3月15日にプラン変更）: 「日割りの金額がおかしい気がする」
- ほかにも月末近くに契約した顧客から似た問い合わせが複数あります。月の途中の日（例: 10日）に契約した顧客の請求書は正しいと言われています。

原因を調べて直してください。

- docs/FORMAT.md のルールが正です。どの契約開始日（29〜31日、うるう年の 2/29 を含む）・どの日付・プラン変更の有無でも、請求書・`periods` の出力・`run` の出力が FORMAT.md どおりになること。
- 出力の形式、コマンドの使い方、関数の呼び出し方は変えないこと。
- tests/、docs/、data/ のファイルは変更しないこと（テストの追加は新しいファイルなら自由）。`python3 -m unittest discover -s tests` が通ること。
- 採点では別のデータ（別の顧客・プラン・日付）で確認します。

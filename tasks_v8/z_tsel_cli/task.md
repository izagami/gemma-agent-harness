`tsel.py` を新しく作ってください。TSV/CSV から列を選び、行を絞り込むコマンドラインツールです（標準ライブラリのみ。1ファイルでもパッケージに分けてもよいが、`python3 tsel.py ...` で動くこと）。あわせて tests/test_tsel.py に unittest のテストを書いてください（テストメソッド8個以上。`python3 -m unittest discover -s tests` で全部通ること）。samples/ に試せるデータがあります。

使い方: `python3 tsel.py [オプション] [FILE ...]`

オプション:
- `-d C` / `--delimiter C` : 区切り文字（1文字）。既定はタブ。`,` のときだけ Python の csv モジュール既定の規則でクォートを解釈し、出力も csv.writer（既定の方言、行末 `\n`）で書く。それ以外の区切り文字では各行を単純に split / join する。
- `-H` / `--no-header` : 入力にヘッダ行がない。列は番号でのみ指定でき、ヘッダは出力しない。
- `-f LIST` / `--fields LIST` : 出力する列。カンマ区切りで、各要素は 列名、1始まりの列番号 `N`、範囲 `N-M`（両端を含む）のいずれか。数字だけの要素は列番号、`数字-数字` は範囲、それ以外は列名として扱う。指定した順に出力し、重複も許す（`-f 2,1,1`）。省略時は全列をそのままの順で出す。
- `-w EXPR` / `--where EXPR` : 行の条件。何回でも指定でき、すべてを満たす行だけを出す。EXPR は `COL=VAL`（一致）、`COL!=VAL`（不一致）、`COL~RE`（`re.search` でマッチ）。EXPR を左から見て最初に現れる演算子の位置で分割する（その位置が `!=` なら `!=`）。例: `note=a=b` は列 note が `a=b` に一致、`x~a=b` は列 x が正規表現 `a=b` にマッチ。VAL は空でもよい。COL は列名か列番号（範囲は不可）。比較は文字列として行う。
- `-n` / `--count` : 行を出さず、条件を満たしたデータ行の数だけを1行で出す（ヘッダも出さない）。
- `-h` / `--help` : 使い方を標準出力に出して終了コード 0。

オプションの書き方は getopt の GNU 形式と同じ: 引数を取らない短いオプションはまとめて書ける（`-nH`）。短いオプションの引数は続けて書いても次の引数でもよい（`-d,`、`-d ,`、`-fname,age`）。長いオプションは `--fields=a,b` と `--fields a,b` の両方。オプションは FILE の後ろに書いてもよい。`--` 以降はすべて FILE として扱う。

入力:
- FILE を省略するか `-` を指定すると標準入力。FILE が複数なら順に連結する。ヘッダありの場合、ヘッダは最初の入力のものを使い、2つ目以降の入力の先頭行（ヘッダ）は出力しない。2つ目以降の入力のヘッダが最初のヘッダとフィールド単位で違えばエラー（0バイトの入力は単に無視する）。
- 文字コードは UTF-8。各入力の先頭の BOM は無視する。行末は `\n` と `\r\n` のどちらも受け付ける。
- 列が足りない行は、足りない列を空文字として扱う。
- 列名・列番号の検査（存在しない列名、範囲外の番号）は、ヘッダありならヘッダで、ヘッダなし（-H）なら最初のデータ行の列数で行う（-H でデータ行が1行もなければ検査しない）。

出力（標準出力、UTF-8、BOMなし、行末 `\n`）:
- ヘッダありなら、まず選んだ列のヘッダ行、次に条件を満たした各行を入力順に。区切り文字は入力と同じ。
- ヘッダありで入力がすべて空（0バイト）なら何も出さない。

終了コード: 条件を満たしたデータ行が1行以上なら 0、0行なら 1（このときもヘッダ行は出す。-n なら `0` を出す）、エラーなら 2。

エラーのときは標準出力に何も出さず（途中まで出力してもいけない）、標準エラーに次のどれか1行を出して終了コード 2:
- 知らないオプション: `tsel: error: unknown option: -x`（長いオプションなら `--xyz` のように `--` 付きの名前）
- オプションの引数がない: `tsel: error: option requires an argument: -d`（長いオプションなら `--fields` のように `--` 付きの名前）
- 区切り文字が1文字でない: `tsel: error: delimiter must be a single character`
- 存在しない列名: `tsel: error: unknown field: NAME`
- 列番号が 0 または列数より大きい: `tsel: error: field index out of range: N`
- 範囲 `N-M` で N > M: `tsel: error: invalid range: N-M`
- -H なのに列名を使った: `tsel: error: field names require a header: NAME`
- EXPR に演算子がない、または COL が空: `tsel: error: invalid expression: EXPR`
- 正規表現が不正: `tsel: error: invalid regex: RE`
- FILE が開けない: `tsel: error: cannot open: FILE`
- ヘッダが一致しない: `tsel: error: header mismatch: FILE`

（NAME・N・EXPR・RE・FILE はコマンドラインに書かれたとおりの文字列。標準入力の FILE は `-`。）

採点では、別のディレクトリをカレントディレクトリにして `python3 <このフォルダ>/tsel.py ...` の形で実行し、標準出力・標準エラー・終了コードを確認します。
